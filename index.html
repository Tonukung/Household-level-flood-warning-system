FLOODWATCH

ระบบเฝ้าระวังระดับน้ำและแจ้งเตือนน้ำท่วมระดับครัวเรือน

IoT สำหรับติดตามระดับน้ำบริเวณบ้านหรือถนนหน้าบ้าน พร้อมแสดงข้อมูลจากเซนเซอร์ และแจ้งเตือนเมื่อพบระดับน้ำหรือค่าจากเซนเซอร์แก๊สผิดปกติ

ภายในเว็บไซต์นี้
เป้าหมาย วิธีทำงาน สิ่งที่ทำแล้ว อุปสรรคและการปรับ ผลและข้อจำกัด บทบาทสมาชิก

01โจทย์และเป้าหมาย

ระบบตรวจวัดและเฝ้าระวังระดับน้ำบริเวณบ้านหรือถนนหน้าบ้านรวมถึงตรวจวัดภาวะเน่าเสียของน้ำเบื้องต้น โดยใช้เซนเซอร์ Ultrasonic วัดระดับน้ำ และเซนเซอร์ตรวจวัดคุณภาพอากาศและแก๊สพิษ โดยส่งข้อมูลผ่าน Wi-Fi ไปยังเว็บไซต์ที่พัฒนาขึ้นเอง เพื่อแสดงระดับน้ำแบบเรียลไทม์ กราฟแสดงแนวโน้มการเปลี่ยนแปลงของระดับน้ำและระบบแจ้งเตือนตามระดับความเสี่ยง และแจ้งภาวะน้ำเน่าเสียเบื้องต้น

เป้าหมายของโครงงานนี้คือการสร้างระบบตรวจวัดและแจ้งเตือนระดับน้ำและคุณภาพอากาศ/แก๊สพิษในบริเวณบ้านหรือถนนหน้าบ้าน โดยใช้เซนเซอร์ Ultrasonic และ MQ-135 ร่วมกับ Arduino UNO R4 WiFi เพื่อส่งข้อมูลไปยังเว็บไซต์ที่พัฒนาขึ้นเอง ซึ่งสามารถแสดงผลแบบเรียลไทม์ กราฟแนวโน้ม และระบบแจ้งเตือนตามระดับความเสี่ยง

02ระบบทำงานอย่างไร

ใช้ Arduino UNO R4 WiFi อ่านระยะจากเซนเซอร์ Ultrasonic แล้วคำนวณระดับน้ำจากความสูง ภาชนะที่กำหนดในโปรแกรม ส่วน MQ-135 อ่านค่า analog เฉลี่ยจากการอ่าน 10 ครั้ง และอ่านสัญญาณ digital เพื่อใช้ประกอบการแจ้งเตือน

01 · ตรวจวัดUltrasonic และ MQ-135 อ่านค่าประมาณทุก 1 วินาที
02 · ประมวลผลArduino คำนวณระดับน้ำและตรวจสถานะเตือน
03 · ส่งข้อมูลส่งข้อมูล JSON ผ่าน Wi-Fi ด้วย MQTT
04 · แสดงผลหน้าเว็บแสดงค่าล่าสุด กราฟ และรายการแจ้งเตือน

อุปกรณ์ยังแสดงผลบน LCD และใช้ buzzer แจ้งเตือนเฉพาะที่ตัวเครื่องได้ โดยมีคำสั่งปิด/เปิดเสียงผ่าน Serial Monitor

03สิ่งที่ลงมือทำแล้ว

อุปกรณ์และโปรแกรมควบคุม

  • อ่านระยะด้วย HC-SR04 และคำนวณระดับน้ำจากความสูงภาชนะ
  • ตรวจจับค่าที่อ่านไม่ได้และส่งค่าวัดเป็น null แทนการแสดงค่าที่ไม่น่าเชื่อถือ
  • อ่านค่า MQ-135, แสดงค่าบน LCD และตั้งเงื่อนไขเตือนด้วย buzzer
  • เชื่อมต่อ Wi-Fi/MQTT ใหม่เมื่อการเชื่อมต่อขาด และส่งข้อมูลตามรอบ

เว็บไซต์และระบบข้อมูล

  • ทำหน้า Dashboard แสดงระดับน้ำ สถานะความเสี่ยง ค่าแก๊ส และสถานะอุปกรณ์
  • ทำกราฟแนวโน้มและรายการแจ้งเตือนจากข้อมูลที่หน้าเว็บได้รับ
  • ทำ backend สำหรับรับ MQTT ตรวจสอบรูปแบบข้อมูล และบันทึกลง SQLite
  • เตรียม API สำหรับข้อมูลล่าสุด ประวัติ สถานะ และรายการแจ้งเตือน

04อุปสรรคและการปรับวิธี

  • ปัจจุบันมีสมาชิกเพียง 2 คน จากปกติ 3 คน เพราะไม่ทราบสาเหตุที่เพื่อนอีกคนไม่เข้าร่วม จึงต้องปรับวิธีทำงานให้เหมาะสมกับจำนวนคน
  • ระยะเวลามีจำกัด จึงใช้ AI ช่วยสร้างโค้ดตัวอย่างและปรับแก้ให้เหมาะสมกับอุปกรณ์และความต้องการของโครงงาน
  • ข้อมูลเซนเซอร์แก๊สแกว่ง โปรแกรมอ่านค่า analog หลายครั้งแล้วเฉลี่ยก่อนนำไปแสดงผล ส่วนการแจ้งเตือนใช้สัญญาณ digital ของโมดูล
  • การแจ้งเตือนต้องไม่ขึ้นซ้ำถี่เกินไป หน้าเว็บตรวจจับช่วงที่ระดับน้ำข้ามเกณฑ์และจำกัดการแจ้งเตือนซ้ำ ขณะที่ตัวอุปกรณ์ควบคุมเสียงเป็นจังหวะและปิดเสียงได้

05ผลที่ได้และข้อจำกัดตอนนี้

  • ทำได้แล้วตรวจวัดและส่งค่าระดับน้ำกับค่า MQ-135 ผ่าน MQTT
  • ทำได้แล้วแสดงข้อมูลสด กราฟ และสถานะเตือนบน Dashboard
  • ทำได้แล้วbackend ตรวจสอบข้อมูลและบันทึกประวัติ/การแจ้งเตือนลง SQLite
  • ยังต้องพัฒนาเชื่อมหน้า Dashboard เข้ากับ API ประวัติและข้อมูลที่ backend บันทึกไว้
  • ยังต้องทดสอบความแม่นยำของเซนเซอร์ การติดตั้งภายนอก และการทำงานต่อเนื่องในสภาพจริง
  • ยังมีข้อจำกัดค่าเกณฑ์และความสูงภาชนะเป็นค่าที่ตั้งไว้ในโปรแกรม ต้องปรับเทียบให้ตรงกับพื้นที่ใช้งาน
